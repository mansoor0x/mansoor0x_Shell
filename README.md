## 📌 نظرة عامة

**Mansoor0x PC Turbo** هي أداة احترافية متكاملة لتحسين وتسريع أداء نظام Windows. تتميز بواجهة سوداء - حمراء جذابة، وتقدم مجموعة واسعة من أدوات التحسين والصيانة.

## ✨ المميزات الرئيسية

### 🚀 التحسين السريع
- **بنقرة واحدة**: تحسين شامل للجهاز بالكامل
- **12 عملية تحسين**: تنظيف، تسريع، تحسين الأداء
- **شريط تقدم**: متابعة عملية التحسين لحظة بلحظة

### 🧹 أدوات التنظيف
- حذف الملفات المؤقتة
- تنظيف كاش المتصفحات (Chrome, Edge, Firefox)
- تفريغ سلة المحذوفات
- إصلاح أخطاء الريجستري
- تنظيف سجلات النظام

### ⚡ تحسينات الأداء
- تحسين أداء الرام
- تفعيل وضع الأداء العالي
- تحسين سرعة الإنترنت
- تحسين أداء الألعاب
- تحسين أداء المعالج
- إلغاء تجزئة الأقراص

### 📊 مراقبة فورية
- استخدام المعالج (CPU)
- استخدام الذاكرة (RAM)
- استخدام القرص الصلب
- عدد العمليات النشطة
- حالة البطارية
- وقت تشغيل النظام
