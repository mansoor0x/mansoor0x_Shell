في هذا المستودع، أقدم لكم واجهة فخمة ومطورة خصيصاً لإدارة السيرفرات واختبار الاختراق الأخلاقي لثغرات الرفع غير المقيد للملفات (**Arbitrary File Upload Vulnerability**). تم تصميم هذه الأداة بشكل مرئي مميز ومريح للعين لتبدو احترافية جداً أثناء تصوير الشروحات ومشاركتها مع المتابعين.

---

## 🚀 الميزات الرئيسية (Features)

* 🗂️ **مستكشف ملفات رسومي (Interactive Explorer):** تصفح المجلدات والملفات بمجرد الضغط عليها دون تعقيد.
* 📝 **محرر أكواد حي (Live Code Editor):** اضغط على أي ملف ليفتح لك كود المحرر المدمج مباشرة، لتعديل الملف وحفظه فوراً على السيرفر.
* 🛡️ **محلل صلاحيات ذكي (Permission Analyzer):** فحص رايات الـ Linux وتلوين المجلدات تلقائياً:
  * 🟢 **[ Writable ]** باللون الأخضر المشع للمجلدات التي تملك صلاحية كتابة كاملة.
  * 🔵 **[ Read-Only ]** باللون الأزرق للملفات المحمية.
* ⚡ **أدوات تحكم سريعة:** رفع ملفات بضغط زر، إنشاء ملفات جديدة، وإنشاء مجلدات في المسار الحالي.
* 💻 **ترمينال مدمج (Embedded Terminal):** لتنفيذ أوامر الـ Shell السريعة في أسفل الواجهة.

## 🎯 خطوات سيناريو الشرح (Exploitation Steps)

### 1️⃣ اكتشاف الثغرة (Discovery)
فحص واجهة الرفع المستهدفة في الموقع (مثل رفع الصور الشخصية أو المستندات) واختبار فلاتر الحماية لتخطيها (عبر تعديل الـ Content-Type أو استخدام الامتدادات المزدوجة).

### 2️⃣ رفع واستدعاء الأداة (Upload & Trigger)
رفع ملف `mansoor0x_manager_v3.0.php` إلى السيرفر، ثم الانتقال إلى رابط الملف مباشرة عبر المتصفح ليفتح لك مدير الملفات الفخم.

### 3️⃣ التحكم الكامل والتحليل (Post-Exploitation)
- استعرض مجلدات السيرفر واكتشف الأماكن الحساسة.
- اضغط على ملفات الـ Configuration لقراءة محتواها وتعديلها عبر الـ **Live Editor**.
- نفذ أوامر التحقق مثل `whoami` أو `id` داخل الترمينال المدمج لاستعراض صلاحيات المستخدم الحالي.

## 🛡️ طرق الحماية الصحيحة (Remediation)

لحماية الأنظمة والمواقع من خطورة هذه الثغرة، يجب تطبيق الاستراتيجيات التالية:
1. **القائمة البيضاء (Whitelisting):** السماح بامتدادات محددة وصارمة فقط للرفع (مثل `.jpg`, `.png`).
2. **عزل الملفات:** تغيير اسم الملف المرفوع تلقائياً إلى اسم عشوائي (UUID) وتخزينه خارج مسار الويب الرئيسي (**Web Root**).
3. **تعطيل التنفيذ:** منع خادم الويب (مثل Apache أو Nginx) من تشغيل أو تنفيذ سكريبتات البرمجة (مثل PHP) داخل مجلد الرفع باستخدام ملف `.htaccess` أو إعدادات السيرفر.
